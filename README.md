# 🍎 사과게임

사과 모양 숫자 타일을 드래그해 합이 10의 배수가 되도록 만드는 60초 퍼즐 게임입니다.

## 게임 소개

8x8 격자에 사과 모양과 1부터 9까지의 숫자가 무작위로 배치됩니다. 상하좌우 또는 대각선으로 이어진 숫자를 드래그해 선택하고, 선택한 숫자의 합이 10, 20, 30처럼 10의 배수이면 선택한 칸이 사라집니다. 제거한 칸 수만큼 점수를 얻으며, 제한 시간 안에 최고 점수에 도전합니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript로 구현했습니다. JavaScript가 격자 생성, 인접 칸 판정, Pointer Events 기반 드래그 선택, 합계 검증, 점수 계산, 60초 타이머를 담당합니다. 최고 점수는 브라우저의 `localStorage`에 저장됩니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 바로 실행할 수 있습니다. 별도의 빌드 도구나 서버는 필요하지 않습니다.

## 커스터마이징한 부분

기본 숫자 합산 규칙을 정확히 10이 아니라 모든 10의 배수로 확장하고, 대각선 선택을 추가했습니다. 숫자 타일에 사과 모양을 표시하며, 사과를 수확하면 위의 사과가 내려오고 빈칸에는 새 사과가 채워집니다. 새 최고 점수를 기록하면 컨페티 효과가 나타나며, 시작 버튼과 다시 플레이 화면, 반응형 레이아웃, 최고 점수 저장, 마우스와 터치도 함께 지원합니다.
